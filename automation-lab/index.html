01 · QUICK CONCEPTS

What makes up a Playwright test?

A basic test brings in Playwright helpers, defines a test, navigates to a page, and asserts what a user should see.

01

Import

test defines a test and expect checks its outcome.

02

Test declaration

The test's callback receives Playwright's page fixture.

03

Navigation

page.goto('/') visits the site's base URL, when Playwright baseURL is configured.

04

Assertion

getByRole finds a heading by its accessible name. toBeVisible() checks that it appears.
