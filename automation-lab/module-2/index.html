01 · QUICK CONCEPTS

Choose locators with intent

Good locators describe what a learner or user can perceive, and target one specific element. A selector that happens to work today may become fragile when the page changes.

01

Role and name

getByRole('link', { name: ... }) identifies an accessible link instead of selecting an arbitrary a tag.

02

Visible labels

getByLabel('Email address') uses the label associated with a form control.

03

Scope duplicates

If two buttons share a name, first find the appropriate region, then the button inside it.

04

Assert a result

await expect(...).toHaveText(...) waits for the expected confirmation.

SIMPLIFIED DOM REFERENCE

Relevant HTML

<a href="/settings">Account settings</a>

<section aria-label="Account details">
  <label for="email">Email address</label>
  <input id="email" type="email" />
  <button>Save changes</button>
</section>

<section aria-label="Notifications">
  <button>Save changes</button>
</section>

<p role="status">Changes saved</p>

The named section is exposed as a region in the accessibility tree. That lets Playwright scope the correct Save button.
