02 · EXPECTED BEHAVIOUR

Acceptance criteria

Use these requirements as the source of truth for your testing decisions.

  1. AC-01

    Display the correct product

    Product 42 displays Canvas Backpack priced at KES 2,400.

  2. AC-02

    Calculate the cart total

    Two Canvas Backpacks produce a cart subtotal of KES 4,800.

  3. AC-03

    Enforce stock boundaries

    Quantities 1 through 5 are accepted. Quantities 0 and 6 are rejected without changing the cart.

  4. AC-04

    Validate checkout email

    An empty or malformed email produces a validation error.

  5. AC-05

    Validate product API response

    GET /api/products/42 returns 200 with id 42, name Canvas Backpack, and priceKES 2400.

  6. AC-06

    Handle a missing product

    GET /api/products/9999 returns 404.

  7. AC-07

    Ensure reliable automation

    Tests use stable locators, meaningful assertions, and isolated test data instead of arbitrary delays.
