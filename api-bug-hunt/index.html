Scenario 1 — POST /api/users

              
Expected: 201 Created, new user ID, and Location header.

              
Seeded defect: The API creates user 103 but responds with 200 OK and omits the Location header. GET /api/users/103 still returns the new user.

            

            

              
Scenario 2 — PATCH /api/users/101

              
Expected: Only the supplied role changes; all other fields stay as they were.

              
Seeded defect: The API changes role to admin but clears the email to an empty string. Follow-up GET shows the unwanted change.

            

            

              
Scenario 3 — DELETE /api/users/102

              
Expected: DELETE returns 204 No Content; GET /api/users/102 subsequently returns 404 Not Found.

              
Seeded defect: The API says 204 No Content but leaves user 102 intact. Follow-up GET returns 200 OK.
