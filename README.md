# Practical QA Lab

Practical QA Lab is an interactive learning platform for practising real-world software quality assurance scenarios.

It is designed to help QA professionals and aspiring testers strengthen practical testing skills through scenario-based exercises, instant feedback and mock interview practice.

## Current Features

### Manual QA Practice
- Real-world testing scenarios
- Investigation and debugging exercises
- Risk-based reasoning
- Weighted scoring
- Instant feedback

### API Testing Practice
- REST API scenarios
- Authentication and authorization
- Data persistence
- Pagination
- Idempotency and payment testing

### SQL Testing Practice
- Database validation
- SELECT queries
- GROUP BY and aggregation
- JOIN scenarios
- Transaction and persistence testing


### QA Mock Interview
- Junior QA interview questions
- Mid-Level QA interview questions
- Weighted answer scoring
- Strong-point feedback
- Improvement recommendations
- Level-specific interview feedback
- Final interview scorecard


## Scoring

Answers are evaluated using structured QA concepts and weighted criteria.

Each scenario is scored out of 10, with higher-value concepts receiving more weight based on their importance to the testing approach.

## Responsive Design

Practical QA Lab supports desktop and mobile layouts, including smaller mobile screens.

## Technology

- HTML
- CSS
- JavaScript

The current version runs entirely in the browser and does not require a backend.

#### How Checkout Bug Hunt Works
Learners review the checkout requirements and
explore a simulated online shop.

They investigate unexpected behaviour, document
their findings and finish the challenge to receive
feedback.

The assessment uses predefined rules, not AI.
Scores are indicative and may not recognize every
valid bug report.

#### Progress Tracking
Checkout Bug Hunt is the seventh learning area.

Completed challenge scores are saved in the
browser and included in progress backups.

Detailed bug reports are stored separately and
are not included in JSON progress backups.

#### Important Notes
- The shop is fictional.
- No real purchases or payments occur.
- Intentional defects are included for learning.
- The platform is not designed for secure exams.
